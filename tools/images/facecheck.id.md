# FaceCheck.ID

> AI-powered facial recognition search engine to find social media profiles, news articles, and web appearances by photo.

---

## Purpose
FaceCheck.ID is an AI-driven facial search engine that indexes publicly accessible photos from social media networks, news articles, blog posts, video platforms, and public arrest databases. It allows investigators to upload a facial image and uncover other instances where the same individual appears online.

## Category
- **Primary**: Image & Forensic Intelligence (`images`)

## Usage

```bash
# Web Interface:
# 1. Visit https://facecheck.id
# 2. Upload a clear facial photo of the target
# 3. Review matches ranked by biometric confidence score
```

## Common Use Cases
1. **Person-of-Interest Identification**: Matching an unidentified subject photo from a crime scene, protest, or online forum to known social media accounts.
2. **Romance Scam & Catfishing Verification**: Verifying whether a profile picture belongs to a real person or is stolen from an influencer/model.
3. **Public Record Correlation**: Checking suspect photos against public mugshot and sex offender registries.

## Input
- Facial photograph (`.jpg`, `.png`, `.webp`).

## Output
- Visual match grid with direct URLs to source websites and biometric similarity confidence scores.
