# Awesome Networking (Nyquist)

> Curated index of modern network engineering tools, high-speed libraries, BGP frameworks, and performance analyzers.

---

## Purpose
Awesome Networking (Nyquist) is a curated index of modern, high-performance network engineering utilities, BGP routing engines, kernel-bypass frameworks (DPDK, XDP), and network telemetry suites for modern Internet infrastructure.

## Common Use Cases
1. **BGP & Internet Topology Research**: Discovering open-source BGP routing daemons and Looking Glass engines for ASN mapping.
2. **High-Speed Network Probing**: Locating kernel-bypass and high-packet-rate scanning frameworks.
3. **Telemetry & Observability**: Referencing industry-standard network monitoring and NetFlow/sFlow collection systems.
