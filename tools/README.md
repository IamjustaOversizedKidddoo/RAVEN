# RAVEN Tool Cards

This directory contains modular tool cards organized by operational category.

## Directory Lifecycle
To maintain a clean and lightweight repository:
* Specific category subdirectories (such as 	ools/usernames/, 	ools/emails/, or 	ools/domains/) are created dynamically only when an upstream tool requiring that category is integrated.
* Each tool is documented as an individual Markdown card (<tool-name>.md) adhering to the standardized template specified in [CONTRIBUTING.md](../CONTRIBUTING.md).
