# System Design 101

> Visual architectural reference and compendium for understanding large-scale distributed systems and infrastructure.

---

## Purpose
System Design 101 (by ByteByteGo) is a widely acclaimed visual encyclopedia explaining how complex distributed systems, cloud computing platforms, databases, CDNs, load balancers, and network architectures function under the hood through concise illustrations and architectural teardowns.

## Common Use Cases
1. **Cloud Architecture Reconnaissance**: Understanding how target CDNs, edge proxies, microservices, and message brokers are structured during enterprise infrastructure analysis.
2. **API & Authentication Topology Analysis**: Understanding OAuth2, JWT validation, and session clustering mechanics during target assessment.
3. **Caching & Database Discovery**: Profiling Redis clusters, database sharding, and Elasticsearch indexing architectures.

## Input
- Architectural research topics (DNS resolution flow, CDN edge caching, cloud load balancer routing).

## Output
- Detailed visual flowcharts, protocol timing diagrams, and architectural breakdowns.
