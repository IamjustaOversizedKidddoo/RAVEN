# Tactical OSINT Cheatsheets

Quick-reference guides for command-line syntax, advanced search operators, and query formats.

* **Search Engine Dorking:** Google, Bing, DuckDuckGo, and Yandex advanced operators.
* **Network & DNS Lookups:** `dig`, `whois`, `nslookup`, `curl`, and ASN queries.
* **Regex for Investigators:** Pattern matching for emails, crypto addresses, phone numbers, and hashes.
* **EXIF & Metadata Tools:** `exiftool`, `strings`, `pdfinfo`, and metadata strippers.
