# Structured OSINT Workflows

Standardized, step-by-step investigative workflows designed to guide researchers from initial target identifier to correlated, verified intelligence.

## Operational Lifecycle

All RAVEN investigative workflows strictly follow the 6-phase intelligence lifecycle:

```
TARGET ➔ DISCOVERY ➔ ENUMERATION ➔ CORRELATION ➔ VERIFICATION ➔ DOCUMENTATION
```
