# OSINT References & Data Sources

Curated indices of public registries, standards, technical documentation, and compliance guidelines.

## Primary Public Registries
* **Corporate Registries:** Global official business directories and registry portals (SEC EDGAR, Companies House, Handelsregister).
* **Aviation & Maritime Standards:** ICAO / IATA codes, MMSI / IMO format standards, and ADS-B protocols.
* **Cryptocurrency Blockchains:** Block explorer APIs, address formats, and clustering standards.
* **Legal Compliance:** GDPR, CCPA, and CFAA boundaries for open-source investigators.

## Technical & Infrastructure Architecture References
* [**System Design 101**](https://github.com/ByteByteGoHq/system-design-101) — Visual compendium for distributed systems, CDN topology, load balancers, and cloud architecture.
* [**Awesome Networking (Facyber)**](https://github.com/facyber/awesome-networking) — Foundational computer networking standards, RFCs, protocol specifications, and troubleshooting tools.
* [**Awesome Networking (Nyquist)**](https://github.com/nyquist/awesome-networking) — Modern network engineering frameworks, BGP routing daemons, telemetry, and packet inspection libraries.
* [**Multiplayer Networking Resources**](https://github.com/0xFA11/MultiplayerNetworkingResources) — Low-level UDP communication, socket engineering, packet serialization, and state synchronization.
